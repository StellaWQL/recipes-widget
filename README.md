# THE RAVEN · 纸剧场

这是整仓库替换包。解压后，`index.html` 就在最外层，可以把全部内容放到原仓库根目录并覆盖同名文件。

## 本次修订

恢复最初那张哑光、灰蓝灰紫、低饱和的纸剧场原图。它与最早两份完整交付包中的图片完全一致。上一版误用了后续重绘的 clean 图片，同名文件已经变亮，本版纠正了这个来源问题。

首页、外围模糊背景和工具窗底纹统一使用 `paper-theatre-original-muted.png`。真正的原图文件原样保留，背景没有经过重新调色或整图重绘。新版水果、翻盖盒、鸽子与信封、左右帷幕、爆米花墙绘及夜蛾书本沿轮廓移植进去。

原鸽子、旧花盒、旧梨子、旧书签和可动花瓣只在各自原位置清理，避免动作时露出旧物重影。局部修补图只在这些小范围内显示。页面脚本和主要样式带本版资源标记，帮助替换后载入新背景。

牌盒按参考照片重新绘制为后侧长边连接的翻盖盒。外盖与盒身统一用灰绿细竖纹和小花，内侧是淡紫衬面、细蕾丝边和少量珍珠点。盖板、盒壁、底板和内衬一起绘制在完整场景中，开合动作按新盒子的四角与后缘重新定位。卡片保持原来的长窄比例，从固定前沿后方露出。

小剧场后墙改为爆米花墙绘。图案与墙面、剧场和新牌盒一起绘制在整张场景里，保留纸纹和褪色颜料的感觉。图案下方留有空墙，舞台地面保持空着。帷幕平时关闭，左右拉开后露出墙绘。

鸽子沿用原插画的折纸造型和姿态，与比例调整后的信封一起绘制为一个完整素材。鸟喙与信封直接相接，两者一起下拉。独立拼接的信封已经移除。

夜蛾是书封本身的平面细线纹样。书本和纹样已经一起绘制在完整底图中。

梨子以完整纸片移动，再由固定的篮沿遮住下端，清理原先露出的暗缝。小剧场的上方短帷幔保持固定，在下方左右滑动的纸帘上投出沿扇贝边缘的柔和阴影。

城市改为逐窗增加暖黄窗光、窗台反光和附近墙面的柔光。亮灯时不替换背景图，天空和云层不会随之变暗。水果使用新版素材，藤篮、花草和其他景物随旧背景恢复。

牌背重新按实际塔罗卡面的长窄比例绘制。原始 240 × 320 图片两侧的黑色留边只在显示时裁掉，实际牌面为 161 × 320。抽牌、翻牌、拖动副本及首页盒内卡片均使用这个比例，原始 78 张牌面文件没有修改。

## 替换方法

1. 解压 ZIP。
2. 将解压出的全部内容放到原仓库根目录，与原来的 `index.html` 放在同一级，覆盖同名项目文件。保留本地仓库自身的 `.git` 目录。
3. 提交到原来发布网页的分支，继续按原来的方式发布。使用 GitHub Pages 时，网页入口位于仓库根目录 `/ (root)`。

页面不需要安装依赖，也不需要执行构建命令。全部 JS、字库、牌面和阅读组件已包含在包内。文件路径兼容 `https://用户名.github.io/仓库名/` 这样的项目子目录地址。

## 使用

首页没有文字提示或发光按钮。鼠标经过物件时，纸片做小幅动作；移开后恢复原位。鸽子还可以按住向下拉，松开后展开生活灵感。

| 物件 | 经过时的动作 | 点击后的功能 |
| --- | --- | --- |
| 左下水果篮 | 一整张梨形纸片向上抽出，篮沿遮住下端 | 菜谱 |
| 左侧小帷幕 | 上檐固定，两张纸帘在阴影下向左右拉开，露出爆米花墙绘 | 电影 |
| 上方纸鸟与信封 | 轻轻下落，可以按住往下拉 | 生活灵感 |
| 右上小城 | 窗内透出暖黄灯光，照亮窗台与附近墙面 | 随机城市 |
| 台阶上的书 | 完整书签沿书页出口向下抽出一点 | 阅读器 |
| 前景细条纹花盒 | 盒盖沿后缘向后翻开，露出内衬与半截手绘纸剧场牌背 | 塔罗 |
| 地面小花瓣 | 轻轻掀动 | 图形工具目录 |

塔罗先洗牌，再从下方牌列任意拖牌到上方解牌区。78 张牌同时放在当前屏幕内，宽屏为 3 行，每行 26 张，窄屏为 6 行，每行 13 张，不需要移动滚动条。鼠标经过哪张牌，就只有那张牌向上抬起。抽走后保留空位，其余牌保持原位，直到再次洗牌。

点击已抽出的牌翻开，也可以继续拖动调整位置。所有牌都是正位，没有固定牌阵或固定抽牌张数。方向键可以在待抽牌之间选择，回车或空格抽取；在解牌区选中牌后，方向键可微调位置。减少动态效果的系统设置也会被遵守。

阅读器支持书架、目录、字号调整、翻页和续读。界面与书内正文均使用汇文明朝体。牌面状态、阅读位置与字号保存在当前浏览器中。

## 数据维护

菜谱和电影优先读取原来的 CSV。继续编辑 `data/atk_recipes_all.csv` 或 `data/movies.csv` 即可，页面刷新后读取更新。原 CSV 无法载入时，使用随包的 JSON 快照。

书源继续使用 `StellaWQL/recipes-widget` 仓库的 `practice` 分支及 `data/books` 目录。12 本书的原文件也已保留在本包中，整套替换仓库时不会删掉这个书源。

书目目录接口为 `https://api.github.com/repos/StellaWQL/recipes-widget/contents/data/books?ref=practice`，书籍使用该接口返回的原仓库下载地址。

## 本地预览

如果需要在本机预览，可以在解压后的目录中运行

```sh
python3 -m http.server 8080
```

然后打开 `http://localhost:8080`。部署到原有静态网站后，直接访问网站即可。
