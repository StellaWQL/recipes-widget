# 书库与阅读器 v4 · 安装与改动说明

## 合并覆盖安装

解压 `THE_RAVEN_Reader_Integrated_v4.zip`，将文件合并到现有网站的根目录。同名文件覆盖，文件夹合并。

| 路径 | 用途 |
| --- | --- |
| `index.html` | 上传的主页基线，增加阅读器入口脚本 |
| `reader.html` | 兼容原阅读器地址 |
| `js/reader-entry.js` | 接入主页书本与阅读入口 |
| `reader-room/` 整个文件夹 | 书库、阅读器、收书桌、脚本、场景图和原始封面 |

不要先删除原来的 `assets/`、`data/`、`js/` 或 `styles/` 目录。本包不包含整套项目，原有城市、素材、字体和 EPUB 仍由本地项目提供。

## 这一版改了什么

- 桌面正文默认改为 17px，手机卷轴改为 16px。首次使用 v4 时更新此前保存的字号，之后保留自行调节的字号。
- 注释标记为正文的 72%，注释正文为正文的 80%。修复《忏悔录》中内联“注”图片被放大的问题，普通插图仍按插图显示。
- 书库去掉查找书和地址输入。右下方的纸函打开新的收书桌，导入本地 EPUB。
- 收书桌是一张完整绘制的画面。纸函、藏书簿和桌面一起生成，手机使用对应竖幅画面。
- 点击纸函选择一本 EPUB，也可以把一本 EPUB 拖到纸函上。取消选择不会改变藏书。损坏文件通过校验前不会登记，文件成功保存后才加入藏书。
- 导入文件沿用原来的本地数据库。已有书籍、原封面和阅读位置继续保留。

## 画面中的操作

| 位置与物件 | 操作 |
| --- | --- |
| 主页书本 | 在当前标签页打开书库 |
| 书库右下方纸函 | 打开收书桌 |
| 收书桌中央纸函 | 选择或接住一本 EPUB |
| 收书桌藏书簿 | 返回书库，也可按 Escape |
| 阅读器左上方折页节目单 | 章节目录与字号 |
| 阅读器左侧目录卡 | 返回书库 |
| 阅读器右上方钥匙 | 返回主页 |
| 阅读器左右线轴 | 桌面向前、向后翻页 |

桌面保留左右双页，J 向后翻、K 向前翻。手机窄屏使用连续卷轴，通过竖向滑动阅读，不使用翻页按钮。手机卷轴上方仍可打开章节、书库和主页。

鼠标移到可互动的物件上时，只让对应物件轻微活动，不显示文字提示。折页、抽卡等动画从完整画面中提取对应部件，并用底图补足移开后的位置。不会拉扯整幅画面，也没有另行生成的物件贴纸。开启减少动态效果时，操作仍可使用。

书库每架在桌面最多展示十二本，手机展示六本。书籍封面保留原图及比例。

## 文件与素材

新增的导入校验模块是 `reader-room/epub-import.js`。它检查 EPUB 压缩包、目录、内容清单和可读取的正文，无需联网校验。

本版新增书库 v4 场景和收书桌场景，并带有动画所需的底图及手机竖图。桌面阅读继续使用花边双页画面，手机阅读继续使用卷轴画面。将 `reader-room/` 整个文件夹合并覆盖即可，不要只复制 HTML。

## 保留现有项目

主页以本次上传的 `index(3).html` 为基线，只增加阅读器入口脚本。原舞台画面、资源路径和“四小时城市”入口保留。

本包不覆盖 `js/app.js`。主页仍引用你的 `app.js?v=17`，上海附近城市数据与其他功能继续使用本地版本。

阅读器复用 `data/books/` 中的 EPUB 和 `assets/fonts/huiwen-mincho.woff2` 字体。本包不覆盖它们。`reader-room/data/catalog.json` 只是阅读器的书库快照，不会替换根目录的 `data/`。

如果本地另行移动了主页、EPUB 或字体，再修改 `reader-room/config.js` 中的相应路径。当前路径沿用已上传的项目结构。

## 本地预览

在项目根目录使用现有静态服务器，或运行：

```bash
python3 -m http.server 8080
```

打开 [http://localhost:8080/](http://localhost:8080/)，从主页进入书库。不要用 `file://` 直接打开 HTML。此覆盖包未部署网站，确认本地效果后，按原站点流程发布即可。

验证范围见 `验收记录.md`。本地 v17 主脚本未上传，未对它的内部逻辑做运行核验；手机布局也不等于已经过 iOS 或安卓真机测试。
