# v4.2 验证记录

验证日期为 2026-11-28。

## 画面与交互

在实际浏览器中检查了桌面书库与 390 × 780 窄屏书库。

- 顶部阴影固定在书架内侧，滚动不带走。
- 滚动到底部，最后一本书完整显示，末层层板和下方支撑都随内容移动。
- 少量藏书的背景补齐，不出现被切断的固定末层。
- 整张书库画面中的钥匙具有彩纸质感。流苏动作使用同一张画面的像素和匹配清底，动作时没有明显硬边。
- 书库仍为上下滚动。没有新增查找功能、分页箭头或鼠标文字提示。
- 收书函正常状态与连接状态在桌面、窄屏纸面范围内显示。连接状态使用独立的静态视觉夹具检查排版，未连接真实服务。
- 现有 Mac 文件夹包导入的书仍能打开，窄屏仍为连续卷轴阅读。

测试不包含真实凭据，也不会产生远程提交。新书从第一个客户端上传，再被第二个客户端读取的场景，已在模拟 GitHub 环境中通过。**真实 GitHub 写入、服务部署及跨真实设备联网验证仍需部署后完成。**
